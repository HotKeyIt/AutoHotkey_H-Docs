HexToBin() [AHK_H]

Convert hex string to binary memory.

OutputVar := HexToBin(Bin, Hex)

Parameters

Bin

Name of variable in which to store binary data.

Hex

Hex string to convert.

Return Value

This function returns the address of bin variable.

Related

#DllImport, DynaCall, WinApi

Examples

VarSetCapacity(v,8,0)
NumPut(0x10101010,&v,"INT64")
hex:=BinToHex(&v,8)
MsgBox % hex
HexToBin(bin,hex)
MsgBox % format("0x{1:X}",NumGet(&bin,"INT64"))
