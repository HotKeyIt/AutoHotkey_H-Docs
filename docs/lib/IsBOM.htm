IsBOM() [AHK_H]

Checks the byte order mark for buffer or address.

OutputVar := IsBOM(AddressOrBuffer , BOM)

Parameters

AddressOrBuffer

Buffer or address to check for a byte order mark.

BOM (optional)

Byte order mark to check for. This parameter can be UTF-8, UTF-16, UTF-16BE, UTF-32 or UTF-32BE only, otherwise empty string will be returned. If no BOM was given and a BOM is found, its name is returned, otherwise CP0 is returned.

Return Value

This function returns the true if a byte order mark was found at given address or buffer. If no BOM was given and a BOM is found, its name is returned, otherwise CP0 is returned.

Examples

FileRead, data, *c %A_ScriptFullPath%
MsgBox % IsBOM(&data) ; Get BOM of the script
MsgBox % IsBOM(&data, "UTF-8") ; Check if script is saved with UTF-8 BOM
