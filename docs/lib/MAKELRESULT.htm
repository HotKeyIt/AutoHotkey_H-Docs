MAKELRESULT() [AHK_H]

Creates a value for use as a return value from a window procedure.

OutputVar := MAKELRESULT(ValueLow, ValueHigh)

Parameters

ValueLow

The low-order value.

ValueHigh

The high-order value.

Return Value

This function returns the lResult value.

Examples

MsgBox % MakeLResult(10, 20)
