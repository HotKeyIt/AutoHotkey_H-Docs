MAKEWPARAM() [AHK_H]

Creates a value for use as an wParam parameter in a message.

OutputVar := MAKEWPARAM(ValueLow, ValueHigh)

Parameters

ValueLow

The low-order value.

ValueHigh

The high-order value.

Return Value

This function returns the lParam value.

Examples

MsgBox % MakeWParam(10, 20)
