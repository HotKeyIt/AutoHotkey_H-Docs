ObjDump() [AHK_H]

Dumps an object to a variable or file so that it can be restored later with ObjLoad().

Size := ObjDump(Object, OutputVar , Mode, Password)
Size := ObjDump(FilePath, Object , Mode, Password)

Parameters

Object

The object to dump. Nested objects are dumped recursively, and an object which is referenced more than once is stored only once.

OutputVar

The variable in which to store the dumped data. Pass &OutputVar to ObjLoad() to restore the object.

FilePath

To write the dump to a file instead, specify the path of the file as the first parameter and the object as the second. An existing file is overwritten.

Mode

If blank or omitted, it defaults to 0. Otherwise, specify the sum of the following values:

1: For each string value, store the full capacity of its field, as set with SetCapacity(). Use this to preserve binary data stored in an object.

2: Compress the dumped data, as with ZipRawMemory().

Password

If Mode includes 2, the password with which to encrypt the compressed data. Ignored otherwise.

Return Value

This function returns the size of the dumped data in bytes, or an empty string on failure.

Remarks

Only keys and values are saved: strings, numbers and nested objects. Struct objects are dumped as a plain object of their fields. Other object types, such as COM objects or function references, are not supported. The object's base is not saved and cannot be restored.

Related

ObjLoad(), ZipRawMemory(), Objects

Examples

Dumps an object to a variable and restores it.

obj := {key: "value", 1: "test", 2: 10, sub: {a: 1}}
size := ObjDump(obj, dump)
copy := ObjLoad(&dump)
MsgBox % copy.key " " copy[1] " " copy.sub.a

Saves an object to a compressed, encrypted file and loads it again.

obj := {name: "AutoHotkey_H", list: [1, 2, 3]}
ObjDump(A_ScriptDir "\obj.bin", obj, 2, "secret")
copy := ObjLoad(A_ScriptDir "\obj.bin", "secret")
MsgBox % copy.name " " copy.list.Length()
