ObjLoad() [AHK_H]

Restores an object from data or a file created by ObjDump().

Object := ObjLoad(AddressOrPath , Password)

Parameters

AddressOrPath

The address of data dumped to a variable, such as &DumpVar, or the path of a file written by ObjDump().

Password

If the data was compressed with a password, the same password. Compressed data is detected and decompressed automatically.

Return Value

This function returns a new object, or an empty string if the file does not exist or cannot be read.

Related

ObjDump(), UnZipRawMemory(), Objects

Examples

Dumps an object to a variable and restores it.

obj := {key: "value", 1: "test", 2: 10}
ObjDump(obj, dump)
copy := ObjLoad(&dump)
MsgBox % copy.key " " copy[1] " " copy[2]
