ResGet() [AHK_H]

Reads a resource from executable file (dll or exe).

Size := ResGet(OutputVar, Executable, Name , Type, Language)

Parameters

OutputVar

The variable in which to store the resource data. Its capacity is set to the size of the data plus two bytes, which are zero.

Executable

Path to the executable file (dll, exe or bin).

Name

The name of resource.

Type (optional)

Type of resource. Default is RCDATA (10).
See MSDN for default resource types.

Language (optional)

The language of resource.

Return Value

This function returns the size of the resource data in bytes, or 0 if the file could not be loaded. If the resource was not found, the return value is blank.

Remarks

If resource data is compressed or encrypted you can use UnZipRawMemory to decrypt and unzip it.

Related

ResPut, ResPutFile ResExist, ResDelete, ResDllCreate, UnZipRawMemory

Examples

sz:=ResGet(data,A_AhkPath,"RESGET.AHK","LIB")
UnZipRawMemory(&data,sz,var)
