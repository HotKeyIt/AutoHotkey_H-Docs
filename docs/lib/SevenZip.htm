SevenZip() [AHK_H]

Loads the 7-Zip module embedded in AutoHotkey.exe and returns an object to create, update, extract, test and list archives.

zip := SevenZip(Hwnd)

Parameters

Hwnd

The ID of a GUI window, which is disabled while 7-Zip compresses or extracts. If omitted, no window is disabled. It can be changed later via the hwnd property.

Return Value

This function returns a SevenZip object. The 7-Zip module is freed when the object is released.

Properties

  • lib: The handle of the 7-Zip module, which is loaded by MemoryLoadLibrary().
  • hwnd: The ID of a GUI window to disable while 7-Zip is working, or 0.

Methods

Add, AutoZip, Benchmark, Check, ClearOwnerWindow, Close, Cmd, ConfigDialog, Delete, Extract, ExtractMem, ExtractMemEx, ExtractRoot, FindFirst, FindNext, GetArcAccessTimeEx, GetArcCompressedSize, GetArcCompressedSizeEx, GetArcCreateTimeEx, GetArcDate, GetArcFileName, GetArcFileSize, GetArcFileSizeEx, GetArcOriginalSize, GetArcOriginalSizeEx, GetArcOSType, GetArcRatio, GetArcTime, GetArcWriteTimeEx, GetAttribute, GetBackGroundMode, GetCompressedSize, GetCompressedSizeEx, GetCP, GetCRC, GetCursorInterval, GetCursorMode, GetDate, GetDefaultPassword, GetFileCount, GetFileName, GetLastError, GetMethod, GetOriginalSize, GetOriginalSizeEx, GetOSType, GetRatio, GetRunning, GetSubVersion, GetTime, GetType, GetVersion, GetWriteTime, GetWriteTimeEx, Hash, IsSFXFile, KillOwnerWindowEx, KillOwnerWindowEx64, List, Open, PasswordDialog, Rename, SetBackGroundMode, SetCP, SetCursorInterval, SetCursorMode, SetDefaultPassword, SetOwnerWindow, SetOwnerWindowEx, SetOwnerWindowEx64, SetPriority, SetUnicodeMode, SfxConfigDialog, SfxFileStoring, Test, Update

Methods which run a 7-Zip command (such as Add and Extract) return the output of 7-Zip and throw an exception with that output if the command fails. Files parameters accept one or more files, folders or wildcard patterns, separated by linefeed (`n), or an array. Options parameters accept 7-Zip command line switches, such as -p for a password or -hide to hide the progress window.

AutoZip

Automated method to add file[s] to archive
If archive already exists it will be re-compressed (extracted, deleted and compressed) with given options, it will be also converted if a different method is used, original archive will be deleted!
If file or path is not an archive or a folder, it will be compressed using same path/name appending method as extension.

Result := zip.AutoZip(Archive, Method, CompressionLevel, Threads, Options)
Return Value

Result reported by 7-zip.

Archive

File name or path of existing archive, file or folder to compress.

Method

One of supported methods. The name will also be used for new file extension.
Default: zip.

CompressionLevel

Compression level 0,1,3,5,7,9 for new archive, see list of supported compression level.
Default: level 9 for maximum compression.

Threads

How many threads to use for compression.
Default: 2 threads.

Options

Additional options valid for Add command.

Callback function created with RegisterCallback() with following parameters:

  typedef BOOL CALLBACK ARCHIVERPROC(HWND _hwnd, UINT _uMsg,
                                     UINT _nState, LPVOID _lpEis);

  hwnd     Window handle.
  Msg     wm_arcextract.
  State   Operation mode.
            0: BEGIN
            1: INPROCESS
            2: END
            3: OPEN
            4: COPY
            5: SKIP
  pEIS    LPEXTRACTINGINFOEX
          typedef struct {
              EXTRACTINGINFO exinfo;  // EXTRACTINGINFO structure
              DWORD dwCompressedSize; // Compressed size
              DWORD dwCRC;            // CRC Checksum
              UINT uOS Type;          // Operation system
              WORD wRatio;            // compression ratio
              WORD wDate;             // change date in MSDOS format
              WORD wTime;             // change time in MSDOS format
              char szAttribute [8];   // file attributes
              char szMode [8];        // compression mode
          } EXTRACTINGINFOEX;

ARCHIVERPROC must return true to continue operation or false to cancel.

If LPARCHIVERPROC is omitted or 0, Window message mode will be used. (wParam = State, lParam = pEIS, hwnd, Msg)

          } EXTRACTINGINFOEX64;

Remarks

SevenZip() is a library function (SevenZip.ahk) in the resources of AutoHotkey.exe; see resource library. It loads 7-zip32.dll or 7-zip64.dll (built from 7-zip32_ungarbled) from resource 556EA2A65AE54D58BC52C792B3ED2ED0 of the current executable, which CleanUpAndPack.ahk adds when AutoHotkey_H is built. The module is loaded from memory, so no DLL file is needed.

7-Zip can create 7z, XZ, BZIP2, GZIP, TAR, ZIP and WIM archives and self-extracting executables, and can extract many more formats, including RAR, CAB, ISO, MSI and VHD. See the 7-Zip website for its FAQ. 7-Zip was written by Igor Pavlov and is licensed under the GNU LGPL.

For zip archives without the 7-Zip module, see ZipCreateFile() and UnZip().

Examples

Creates a 7z archive of a file, then extracts it into a folder.

zip := SevenZip()
FileDelete, %A_Temp%\7z_test.*
FileAppend, Hello 7-Zip, %A_Temp%\7z_test.txt
zip.Add(A_Temp "\7z_test.7z", A_Temp "\7z_test.txt", "-hide")
MsgBox % "Files in archive: " zip.GetFileCount(A_Temp "\7z_test.7z")
zip.Extract(A_Temp "\7z_test.7z", A_Temp "\7z_test_out", "", "-y -hide")
FileRead, text, %A_Temp%\7z_test_out\7z_test.txt
MsgBox % text

Creates a zip archive of two files and extracts one of them to memory.

zip := SevenZip()
FileDelete, %A_Temp%\7z_test.zip
FileDelete, %A_Temp%\7z_?.txt
FileAppend, first, %A_Temp%\7z_a.txt
FileAppend, second, %A_Temp%\7z_b.txt
zip.Add(A_Temp "\7z_test.zip", [A_Temp "\7z_a.txt", A_Temp "\7z_b.txt"], "-tzip -hide")
size := zip.ExtractMem(buf, A_Temp "\7z_test.zip", "7z_b.txt", "-hide")
MsgBox % StrGet(&buf, size, "UTF-8")

Lists the files in an archive.

zip := SevenZip()
for i, file in zip.List(A_Temp "\7z_test.zip")
    list .= file[6] "`t" file[4] " bytes`n"
MsgBox % list
