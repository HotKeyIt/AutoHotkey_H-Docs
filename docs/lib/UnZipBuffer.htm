UnZipBuffer() [AHK_H]

Extracts one item from a zip archive on disk or in memory into a variable.

Size := UnZipBuffer(ZipFileName, Item , OutputVar, Password)
Size := UnZipBuffer(Address, ZipSize, Item , OutputVar, Password)

Parameters

ZipFileName

The path and name of the zip archive to extract from.

Address, ZipSize

Alternatively, the address of a zip archive in memory (a pure integer) followed by its size in bytes. For example, &ZipData, Size where ZipData was filled by ZipCloseBuffer().

Item

The relative path and name of the item within the archive, or its zero-based index. If blank or omitted, the first item (index 0) is extracted.

OutputVar

If omitted, only the uncompressed size of the item is returned. Otherwise, specify a variable in which to store the extracted data. Its capacity is adjusted as needed and the data is followed by a binary zero (two bytes), so text can be retrieved with StrGet().

Password

The password of the archive, if it is encrypted.

Return Value

This function returns the uncompressed size of the item in bytes, or an empty string if no item with the specified name was found.

Error Handling

An exception is thrown if the archive cannot be opened or the item cannot be extracted, or if Address is given but ZipSize is not numeric.

Related

ZipCreateBuffer(), ZipAddBuffer(), ZipCloseBuffer(), ZipCreateFile(), ZipAddFile(), ZipCloseFile(), UnZip(), ZipInfo(), ZipRawMemory(), UnZipRawMemory()

Examples

Extracts a file from a zip archive on disk.

size := UnZipBuffer("C:\Test.zip", "Test.txt", data)
MsgBox % StrGet(&data, size, "UTF-8")

Creates a zip archive in memory and extracts the item again.

text := "Hello from a zip archive in memory"
hZip := ZipCreateBuffer(1024 * 1024)
ZipAddBuffer(hZip, &text, StrLen(text) * 2, "hello.txt")
zipSize := ZipCloseBuffer(hZip, zipData)
UnZipBuffer(&zipData, zipSize, "hello.txt", out)
MsgBox % StrGet(&out)
