UnZipRawMemory() [AHK_H]

Decompresses and optionally decrypts raw memory created by ZipRawMemory(), for example a resource.

Size := UnZipRawMemory(Address, Size , OutputVar, Password)

Parameters

Address

The address of the compressed data, such as &MyVar.

Size

The size of the compressed data in bytes.

OutputVar

If omitted, the data is decompressed but only its size is returned. Otherwise, specify a variable in which to store the decompressed data, or an address (a number greater than 1024) to copy it to. A variable's capacity is adjusted as needed and the data is followed by a binary zero (two bytes).

Password

The password that was used to encrypt the data, if any.

Return Value

This function returns the size of the decompressed data in bytes, or an empty string on failure (for example, if the data is not in the format produced by ZipRawMemory()).

Remarks

Ahk2Exe uses ZipRawMemory() to compress and encrypt resources in raw mode (only one file, string or block of memory per call). AutoHotkey decompresses such resources automatically (compiled script, AutoHotkey.dll, WinApi and library resources). This function can be used by a script to decompress and decrypt raw resources itself.

Related

ZipRawMemory(), CryptAES(), ResGet(), ZipCreateBuffer(), UnZipBuffer(), ZipCreateFile(), UnZip()

Examples

Compresses and encrypts a string, then restores it.

text := "This is a message from AutoHotkey."
size := ZipRawMemory(&text, StrLen(text) * 2 + 2, zipped, "password")
UnZipRawMemory(&zipped, size, restored, "password")
MsgBox % StrGet(&restored)

Reads a library script from the resources of AutoHotkey.exe (as embedded by the AutoHotkey_H build process) and decompresses it.

size := ResGet(res, A_AhkPath, "AHKTHREAD.AHK", "LIB")
UnZipRawMemory(&res, size, script)
MsgBox % StrGet(&script, "UTF-8")
