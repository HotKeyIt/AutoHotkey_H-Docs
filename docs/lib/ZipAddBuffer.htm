ZipAddBuffer() [AHK_H]

Adds data from memory as a file to a zip archive created with ZipCreateBuffer() or ZipCreateFile().

ZipAddBuffer(ZipHandle, Address, Size, FileName)

Parameters

ZipHandle

The zip handle returned by ZipCreateBuffer() or ZipCreateFile().

Address

The address of the data to add, such as &MyVar.

Size

The size of the data in bytes. For a string in a Unicode build, this is StrLen(MyVar) * 2.

FileName

The name (optionally including a relative path) the data will have inside the archive.

Return Value

This function returns 1 on success.

Error Handling

An exception is thrown if ZipHandle is zero or the data could not be added.

Related

ZipCreateBuffer(), ZipCloseBuffer(), UnZipBuffer(), ZipCreateFile(), ZipAddFile(), ZipAddFolder(), ZipCloseFile(), ZipOptions(), UnZip(), ZipInfo()

Examples

Compresses a script into a zip archive in memory.

script := "MsgBox Hello World!"
hZip := ZipCreateBuffer(1024 * 1024)
ZipAddBuffer(hZip, &script, StrLen(script) * 2, "MyScript.ahk")
zipSize := ZipCloseBuffer(hZip, zipData)
MsgBox % "The archive is " zipSize " bytes."
