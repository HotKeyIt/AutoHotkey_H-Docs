ZipCloseBuffer() [AHK_H]

Closes a zip archive created with ZipCreateBuffer(), stores it in a variable and returns its size.

Size := ZipCloseBuffer(ZipHandle, OutputVar)

Parameters

ZipHandle

The zip handle returned by ZipCreateBuffer().

OutputVar

The variable in which to store the zip archive. Its capacity is adjusted as needed. Use &OutputVar to pass the archive to functions which expect an address, such as UnZipBuffer() or File.RawWrite().

Return Value

This function returns the size of the zip archive in bytes.

Error Handling

An exception is thrown if OutputVar is not a variable or the archive could not be finalized.

Related

ZipCreateBuffer(), ZipAddBuffer(), UnZipBuffer(), ZipCreateFile(), ZipAddFile(), ZipCloseFile(), ZipOptions(), UnZip(), ZipInfo(), ZipRawMemory()

Examples

Creates a zip archive in memory and saves it to a file.

text := "Some text to compress"
hZip := ZipCreateBuffer(1024 * 1024)
ZipAddBuffer(hZip, &text, StrLen(text) * 2, "text.txt")
zipSize := ZipCloseBuffer(hZip, zipData)
FileOpen(A_Temp "\test.zip", "w").RawWrite(zipData, zipSize)
