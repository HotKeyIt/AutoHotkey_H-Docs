ahkLabel() [AHK_H DLL/EXE export]

Allows calling a Label in script currently executed by AutoHotkey module.
Parameters can be strings only as well as return value.

OutputVar := DllCall("Module\ahkLabel", "Str", "LabelName", "UInt", DoNotWait, "CDecl Int")

Parameters

LabelName

The name of the label to jump to.

DoNotWait

1 (true) will not wait for the code to finish / return, FALSE / NULL / 0 will wait for execution to finish like GoSub does.

Return Value

This function returns the 1 / true if label was found or 0 / false otherwise.

Related

ahkPostFunction, ahkFindFunc, DllCall

Examples

dllpath := A_AhkDir "\AutoHotkey.dll"
DllCall("LoadLibrary", "Str", dllpath) ; Load the AutoHotkey module.
script := "
(
#Persistent
Return
MyLabel:
MsgBox % A_ThisLabel
Return
)"
DllCall(dllpath "\ahktextdll", "Str", script, "Str", "", "Str", "", "CDecl") ; Start a new thread with the script.
while !DllCall(dllpath "\ahkReady")
    Sleep 50
DllCall(dllpath "\ahkLabel", "Str", "MyLabel", "UInt", 0, "CDecl") ; Gosub the label and wait for it to return.

; Same example as above using the AutoHotkey.dll included in AutoHotkey.exe's resources.
dll := AhkThread(script)
while !dll.ahkReady()
    Sleep 50
dll.ahkLabel["MyLabel"]
